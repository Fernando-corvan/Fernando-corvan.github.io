# CASA CORVAN — Portal público

Sitio estático institucional de CASA CORVAN.

- **URL prevista:** https://fernando-corvan.github.io/
- **Contenido público:** arquitectura de alto nivel, líneas de investigación y principios de trabajo.
- **Memoria persistente privada:** [corvan-agent-memory](https://github.com/Fernando-corvan/corvan-agent-memory), existente y gobernada por sus propios contratos de autorización y admisión.
- **Visión de memoria distribuida:** [vision-casa-corvan](https://github.com/Fernando-corvan/vision-casa-corvan), repositorio privado independiente.

## Límite de publicación

No subir estados operativos, bitácoras internas, claves, secretos, configuraciones de acceso ni documentos privados a este repositorio. Las páginas de GitHub Pages se publican como contenido accesible por internet.
